## What Each Service Does

| Service | What It Does | Why We Need It |
|---------|--------------|----------------|
| **Vercel** | Hosts the website/app | Users access the platform here |
| **DigitalOcean** | Runs the backend code | Processes all requests & logic |
| **MongoDB** | Stores all data | Users, messages, communities |
| **Agora** | Voice & video calls | Real-time communication |
| **Cloudinary** | Stores images/files | Profile pics, uploads, media |
| **Brevo** | Sends emails | Invites, OTP codes, alerts |

---

## Scaling Costs

As you grow, costs increase mainly due to:

1. **Agora** - More call minutes = higher cost
2. **MongoDB** - More data = larger database needed
3. **Cloudinary** - More uploads = more storage needed
